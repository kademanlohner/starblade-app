Starblade Academy

For Parents

Starblade Academy is a learning game: math, reading, writing, drawing, geography, and a pet dragon. This page is for grown-ups.

How to open and install

Open the Starblade Academy page in the browser on the phone or tablet.

iPhone or iPad: open it in Safari. Tap Share (the square with an arrow). Tap Add to Home Screen. Tap Add.

Android: open it in Chrome. Tap the three-dot menu. Tap Install app or Add to Home screen. Confirm.

The icon opens like an app. After the first online visit, it can also open offline.

How progress is saved

Each device keeps its own progress. There is no account and no sign-in. Stars, stories, sketches, and the dragon stay on that device, in that browser or in the home-screen icon. They are not sent to anyone.

On one device, each child picks a name. Their stars stay their own. Those stars also add together to help the dragon grow.

On an iPhone, Safari and the home-screen icon can keep two separate saves. After you install it, keep opening the icon.

Days played, stars, and the dragon stage only go up. Skipping a day does not take them away. A grown-up can still erase one explorer with Reset in Grown-ups, or by clearing this site in the browser.

How to back up or move it

Do this before a new phone, or before anyone clears the browser.

  1. Open the app and tap Grown-ups.
  2. Press and hold the button for 3 seconds.
  3. Tap Export progress. Keep the file somewhere you control. The app does not upload it. The file includes sketches.
  4. On the new device, install the app, open Grown-ups the same way, and tap Import progress. Choose the file.

Import replaces the explorer who is open on that device. Other explorers on that device stay as they are.

Copy backup code and Restore from a code work too. The code does not include sketches. The file does.

How updates arrive

Open the app once while the device is online. It saves the newest copy and can open offline after that. This is not an App Store or Google Play update. The icon does not update through Apple or Google. If the device stays offline, it keeps the last copy it already saved.
