# Starblade Academy

A galaxy learning game for kids: math, reading, writing, drawing, geography and a pet dragon that grows as you practice.

**Open / install:** see [For Parents](for-parents.html).

- iPhone / iPad: open the page in Safari, tap Share, then **Add to Home Screen**.
- Android: open the page in Chrome, tap the menu, then **Install app** (or **Add to Home screen**).

Progress is saved only on the device that is used. No accounts, ads, tracking or data collection. See [privacy.html](privacy.html).

This repository holds the built app only; it is deployed automatically by GitHub Pages.

Store listing text is in [store/listing.md](store/listing.md). The iOS and Android projects use Capacitor. See `package.json`.
